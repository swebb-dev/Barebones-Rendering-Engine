# Barebones Rendering Engine
This was a project to get used to OpenGL, GLAD, and GLFW.
Project can be launched by just typing 'make' in the working directory.
Camera can zoom in and out using the scroll wheel.
Object can be moved by using WASD.
NOTE: The cat is messed up, since it uses ngons. Other models restricted to triangles will function.
NOTE: The trex is much bigger than the camera, so you will need to zoom out to see anything.
